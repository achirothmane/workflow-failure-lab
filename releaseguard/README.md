# ReleaseGuard for n8n

Measured, transactional canary releases for synchronous read-only JSON workflows.

This build is under adversarial validation. Production and publishing verdicts will be recorded after the real n8n integration run.

Install: `npm ci` (tested package includes its lockfile). Run the service with the variables in `.env.example`, or use `compose.yaml`. Import the four workflow JSON files and configure Header Auth credentials. See the completed setup and review documents in the packaged deliverable.
